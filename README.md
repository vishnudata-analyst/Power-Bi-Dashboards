# Marketing Campaign ROI Analysis

## Project Overview
This project analyzes marketing campaign performance and ROI using Microsoft Power BI.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Highlights
- Campaign performance analysis
- ROI analysis
- Revenue and cost comparison
- Key performance indicators
- Interactive dashboard visualizations

## Files Included
- Power BI .pbix file
- Project presentation .pptx

## Objective
The objective of this project is to analyze marketing campaign performance and identify key insights that can help in evaluating campaign effectiveness and return on investment.
